What Is a HEX Color Code?

A HEX color code is a six-character hexadecimal value used to represent colors in websites, graphic design and other digital applications. For example, #FF0000 represents red.

What Is an RGB Color Code?

RGB stands for Red, Green and Blue. An RGB value represents a color using three numerical values that describe the amount of red, green and blue in the selected color.
