What is Image Metadata?

Image metadata is information associated with an image file. Depending on the file, metadata can include details such as file name, file type, dimensions, file size and other technical information.

How to View Image Information

1. Tap Choose an Image and select a JPG, JPEG, PNG or WebP file.

2. The image preview and available basic file information will appear automatically.

3. Check the file name, size, format, dimensions, aspect ratio and modification date.

Is this image metadata viewer free?

Yes. This image information viewer is free to use and works directly in your browser.

Are my images uploaded?

No. The basic image information is read locally in your browser. Your selected image does not need to be uploaded to a server.

Which image formats are supported?

The tool supports JPG, JPEG, PNG and WebP images and displays basic technical information about the selected file.
