How to Resize an Image Online

1. Tap the Choose Image button and select your JPG, JPEG or PNG image.

2. Enter the new width and height in pixels.

3. Tap Resize Image to create the resized image.

4. Tap Download Resized Image to save the resized image.

Is this image resizer free?

Yes. ImageTools provides this online image resizer free of charge. No software installation is required.

Can I resize an image by pixels?

Yes. You can enter the exact width and height in pixels and create a resized version of your image.

Is my image uploaded to a server?

The resizing process is performed directly in your browser. The tool does not need to upload your image to a server for resizing.
