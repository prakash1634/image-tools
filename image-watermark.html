What is an image watermark?

A watermark is text or a visual mark placed over an image to identify the owner, creator, brand or source of the image. Watermarks can also help discourage unauthorized use.

Is this watermark tool free?

Yes. This image watermark tool is free to use. You can add text watermarks without installing additional software.

Which image formats are supported?

The tool supports JPG, JPEG, PNG and WebP images. The watermarked result is downloaded as a PNG image.

Are my images uploaded?

No. The watermark is created directly in your browser. Your image does not need to be uploaded to a server.
